# Эмулятор командной оболочки

Вариант №28. Практическая работа №1 по дисциплине
«Конфигурационное управление», РТУ МИРЭА, ИКБО-40-25.

## Описание

GUI-эмулятор командной оболочки UNIX-подобной ОС.
Работает с виртуальной файловой системой (VFS), размещённой в памяти.
Источником VFS является ZIP-архив; данные архива не распаковываются
на диск и не модифицируются.

## Структура проекта

| Путь | Назначение |
|------|------------|
| `src/shell.py` | ядро эмулятора: разбор строки и выполнение команд |
| `src/gui.py`   | графический интерфейс на Tkinter |
| `src/main.py`  | точка входа, разбор параметров командной строки |
| `tests/`       | модульные тесты ядра |

## Запуск

    ./run.sh

## Тесты

    python3 -m unittest discover tests

## Команды эмулятора

| Команда | Описание |
|---------|----------|
| `ls`    | заглушка: выводит своё имя и аргументы (этап 1) |
| `cd`    | заглушка: выводит своё имя и аргументы (этап 1) |
| `exit`  | завершение работы эмулятора |
